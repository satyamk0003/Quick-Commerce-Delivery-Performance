# 📈 Retail Sales & Quick-Commerce Operational Performance Analytics

## 📝 Project Overview
This repository contains a comprehensive data analytics and business intelligence portfolio built using **Advanced Excel**. The project evaluates multi-channel business scenarios, including E-commerce performance, Marketplace metrics, and **Quick-Commerce Hyperlocal Delivery Operations** across multiple store hubs.

---

## 🚀 Key Business Scenarios Analyzed

### 1. ⚡ Quick-Commerce Delivery Logistics Analysis
* **Objective:** In-depth evaluation of store-level logistics to reduce delivery service level agreement (SLA) breaches.
* **Key Metrics Inferred:** Analyzed **7,871 orders** across various micro-hubs (Kankarbagh, Boring Road, Ashiyana, etc.).
* **Insights Driven:** 
  * Identified that **Tribhuvan hub** achieved the fastest delivery average (**11.6 minutes**).
  * Flagged delivery bottlenecks at **Ashiyana hub** (averaging **21.5 minutes**).
  * Mapped order distribution trends showing a massive spike in **April (5,974 orders)** compared to March and May.

### 2. 🛍️ E-Commerce & Meesho-Marketplace Sales BI
* **Objective:** Profitability mapping, revenue leakage identification, and promotional efficiency.
* **Key Functions Used:** `Pivot Tables`, `XLOOKUP`, `SUMIFS`, `Profit Margin %` calculation models.
* **Insights Driven:** 
  * Tracked a gross total of **₹80.93M** in e-commerce GMV.
  * Computed marketplace profit parameters yielding **₹7.05M profit** with a healthy **41.9% profit margin**.
  * Evaluated regional demand; **Maharashtra** and **Punjab** emerged as top revenue-generating clusters.
